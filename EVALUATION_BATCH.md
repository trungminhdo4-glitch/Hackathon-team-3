# Ten live SaaSLens investigations

**One of ten verdicts matched the dataset reviewer.** GPT-6.2 Astra returned six Yellow verdicts and four Insufficient evidence verdicts. All ten requests finished. The reviewer assigned three Green, four Yellow and three Red. This batch shows that a stronger model can recover a useful distinction on Copilot Chat while the overall classifier still needs work.

We selected rows 1–10 in file order before testing. Each investigation received the original URL and a model ID. The reviewer’s product description, label, reasoning and notes were withheld until comparison. Both search and assessment used `gpt-6.2-astra` at low reasoning effort. Runs used the live Node API with three concurrent cases. Rows 2 and 6 had appeared in earlier development checks. The other eight were new to this calibration. We did not run a paired ten-case comparison with GPT-4.1.

### What the batch measures

Agreement here measures whether a fresh, URL-only investigation reproduced a particular human judgment. It includes every abstention. Several dataset rows name a specific edition or business concern that the URL alone does not identify. Sources also change. In particular, finding several readable pages and validating the specific passage that decides a verdict are separate steps. The research activity view records the former, while report citations identify the latter.

To repeat the comparison, start SaaSLens and run `python tests/calibrate.py --model gpt-6.2-astra --jobs 3 --output batch.jsonl`. Each record includes the actual verdict, the reviewer's reasoning, cited findings, limitations, and research activity. Repeated live searches can retrieve different passages.
